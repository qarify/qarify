# 첫 번째 테스트 (튜토리얼)

QArify 설치를 마쳤다면, 이제 가장 중요한 첫 테스트를 만들어 볼 시간입니다\! 🚀

이 튜토리얼에서는 간단한 **로그인 시나리오**를 자동화하며 QArify의 핵심적인 녹화, 실행, 결과 확인 과정을 **5분 안**에 경험하게 됩니다.

---

### **Step 1. 테스트 시나리오 구상하기 ✍️**

먼저 어떤 테스트를 만들지 정해야 합니다. 가장 대표적인 시나리오인 '로그인'을 자동화해 보겠습니다.

- **테스트 목표**: 사용자가 올바른 아이디와 비밀번호를 입력했을 때, 성공적으로 로그인되어 환영 메시지가 표시되는지 확인한다.
- **테스트 절차**:
  1.  로그인 페이지로 이동한다.
  2.  아이디 입력창에 `testuser`를 입력한다.
  3.  비밀번호 입력창에 `password123`를 입력한다.
  4.  '로그인' 버튼을 클릭한다.
  5.  로그인 후 페이지에 'Welcome, testuser\!'라는 텍스트가 보이는지 **검증**한다.

---

### **Step 2. 테스트 녹화하기 🎥**

이제 터미널에 `qy start` 명령어를 입력하여 테스트 녹화를 시작합니다. 이 명령어는 명시한 테스트 웹사이트를 새로운 브라우저 창으로 엽니다.

1.  **터미널에 아래 명령어를 입력하세요.** (테스트할 페이지의 URL을 뒤에 붙여줍니다)

    ```bash
    qy start https://qarify.github.io/qy-docs/test-pages/login
    ```

2.  **명령어를 실행하면 `Web Agent`와 함께 브라우저 창이 나타납니다.**
    - **Web Agent**는 테스트 페이지의 녹화 및 실행을 위한 컨트롤러 역할을 제공합니다.<br/>
      <img src="/img/qy-web-agent.png" alt="QArify Web Agent" width="200" />
    - `Web Agent` 상의 녹화 버튼(<Mic size={14} color={'red'}/>)을 클릭해서 녹화를 시작하세요.

3.  **웹사이트 창에서 위에서 구상한 시나리오대로 행동하세요.**
    - 아이디 입력창을 클릭하고 `testuser`를 입력합니다.
    - 비밀번호 입력창을 클릭하고 `password123`를 입력합니다.
    - 로그인 버튼을 클릭합니다.

4.  **가장 중요한 '검증' 단계를 추가합니다.**
    - 로그인 성공 후, 환영 메시지인 'Welcome, testuser\!' 텍스트가 나타납니다.
    - `Web Agent` 상의 검증 버튼(<HatGlasses size={14} color={'red'}/>)을 클릭하고 페이지 상의 환영 메시지를 선택하세요.
    - `Web Agent` 상에 'Expect element' 항목의 'is visible'(기본값)을 선택 후 'Add Verification' 버튼을 클릭합니다.
    - 이제 "이 텍스트가 반드시 보여야 한다"는 검증 단계가 테스트에 추가되었습니다. 이것이 바로 자동화된 테스트의 핵심입니다.

    👉 `Web Agent` 상단에는 선택된 엘리먼트들의 `selector` 정보가 표시됩니다.

5.  **녹화를 종료하고 테스트를 확인합니다.**
    - `Web Agent` 상의 녹화 종료(<CircleStop size={14} color={'red'}/>)을 클릭해서 녹화를 종료하세요.

---

### **Step 3. 테스트 실행하기 ▶️**

이제 방금 녹화한 테스트를 실행하여 QArify가 여러분을 대신해 테스트를 수행하도록 할 차례입니다.

1.  **`Web Agent` 상의 실행 버튼(<Play size={14} color={'green'}/>)을 클릭해서 테스트를 실행하세요**
    - 녹화했던 로그인 과정이 눈앞에서 빠르게 재현됩니다.

2.  **`Studio` 상에서 실행하기**
    - **Studio**는 웹 브라우저 상에서 테스트 관리 기능을 제공합니다.
    - `Web Agent` 상의 상태 표시 버튼(<Wifi size={14} color={'green'}/>)을 클릭해서 `Studio`를 새로운 브라우저 창으로 엽니다.
    - 왼쪽 패널에 방금 전 녹화를 통해 생성된 테스트를 선택하고 마우스 오른쪽 클릭 후 Run Test(<Play size={14} color={'green'}/>)를 클릭해서 테스트를 실행하세요.

3.  **터미널 상에서 실행하기**
    - 터미널에 아래 명령어를 입력하세요.

    ```bash
    qy run --config ./qarify.config.json --reporter junit
    ```

    - 명령어를 실행하면 잠시 후 브라우저가 자동으로 열리고, 테스트기 진행된 후 테스트가 끝나면 브라우저는 자동으로 닫힙니다.

    👉 `qarify.config.json`은 QArify 프로젝트의 설정 파일입니다. `qy start` command를 실행했던 디렉토리 상에 기본값으로 자동 생성됩니다.

---

### **Step 4. 결과 확인하기 📊**

테스트 실행이 완료되면, QArify는 모든 과정과 결과를 담은 리포트를 자동으로 생성합니다.

1.  **프로젝트 폴더에 생성된 `.qarify` 디렉토리를 확인하세요.**
    - `reports` 폴더에는 실행 시 명시한 report file이 저장됩니다.
    - `attachments`와 `logs` 폴더에는 각각 screenshot 파일들과 로그 파일들이 저장됩니다.

    👉 현재 지원되는 report type들은 `json`, `junit`입니다.

### 🎉 **축하합니다\!**

QArify를 사용하여 첫 번째 웹 자동화 테스트를 성공적으로 생성하고 실행했습니다. 이제 이 과정을 응용하여 더 복잡하고 다양한 시나리오를 자동화할 수 있습니다.
