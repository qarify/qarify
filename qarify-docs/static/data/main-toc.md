## **Documentation Site Main Menu**

- ### **Overview**
  - **What is QArify?**: An introduction to the service, its goals, and the problems it solves.
  - **Key Features**: A detailed breakdown of QArify's capabilities.
  - **Roadmap**: Information on the current version (V1) and future plans.

- ### **Getting Started**
  - **Installation**: Simple instructions on how to install the QArify CLI.
  - **Project Setup**: Guidance on using the `qy init` command to start a new project.
  - **Your First Test**: A step-by-step tutorial based on the user scenarios to create and run a basic test.

- ### **Guides**
  - **Using the Test Studio**: How to use `qy start` for recording test scenarios.
  - **Managing Tests**: Instructions on creating, editing, and organizing test suites and cases.
  - **Running Tests & Analyzing Results**: Details on executing tests via the CLI and interpreting the output reports.
  - **Authentication**: How to log in and manage user authentication via the CLI.

- ### **Reference**
  - **CLI Commands**: A comprehensive reference for all available CLI commands and their options.
  - **Configuration**: Detailed explanation of the `.qarifyrc.json` configuration file.
  - **Type Definitions**: API-style documentation for the TypeScript types used in the project.
