# Roadmap

- Current Version (V1): Supports test automation for web browser-based applications. Key features include project management via the CLI, scenario recording with Test Studio, and test execution and results analysis.
- Future Plans:
  - Support for test automation of mobile (Android, iOS) applications
  - Support for a plugin architecture for customization
  - Support for MCP (Model Context Protocol)
  - Enhanced support for integration with various test frameworks
  - CI/CD pipeline integration
  - Advanced test result analysis and reporting features
